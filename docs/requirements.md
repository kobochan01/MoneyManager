# 要件定義書 — MoneyManager

作成日: 2026-05-31

---

## 1. プロジェクト概要

家族・同居人が共同で利用できる家計簿Webアプリケーション。
収支の記録・カテゴリ管理・カレンダー表示・固定費管理を中心に、
ユーザーごとに締め日を設定できる実用的な家計管理ツール。

---

## 2. 技術スタック

| カテゴリ | 技術 |
|---|---|
| フロントエンド | Vue.js 3 |
| バックエンド | Ruby on Rails 8（API mode） |
| データベース | MySQL 8 |
| コンテナ | Docker / Docker Compose |

---

## 3. 機能要件

### 3-1. 認証・ユーザー管理

| # | 機能 | 詳細 |
|---|---|---|
| A-1 | ユーザー登録 | 名前・メールアドレス・パスワードで登録 |
| A-2 | ログイン / ログアウト | メール＋パスワード認証 |
| A-3 | 招待機能 | 既存ユーザーがメールでほかのユーザーを家計簿グループへ招待 |
| A-4 | グループ管理 | 1グループ（家計簿）に複数ユーザーが所属できる |

---

### 3-2. 収支記録

| # | 機能 | 詳細 |
|---|---|---|
| B-1 | 収入登録 | 日付・金額・カテゴリ・メモを入力 |
| B-2 | 支出登録 | 日付・金額・カテゴリ・メモを入力 |
| B-3 | 編集 / 削除 | 登録済みの収支を編集・削除できる |
| B-4 | 複数収入対応 | 同月内に複数の収入を登録可能（給与＋副業など） |

---

### 3-3. カテゴリ管理

| # | 機能 | 詳細 |
|---|---|---|
| C-1 | 自由入力 | 初回は自由テキストでカテゴリを入力 |
| C-2 | 選択式（2回目以降） | 過去に入力したカテゴリをサジェスト・選択できる |
| C-3 | グループ共有 | カテゴリはグループ内で共有される |

---

### 3-4. 固定費管理

| # | 機能 | 詳細 |
|---|---|---|
| D-1 | 固定費登録 | 名前・金額・引き落とし日・カテゴリを設定 |
| D-2 | 毎月自動反映 | 登録した固定費は毎月の支出として自動的に計上される |
| D-3 | 引き落とし日ルール | 引き落とし日が土日祝の場合、翌営業日に自動ずらし（日本の祝日カレンダー対応） |
| D-4 | 固定費の編集 / 削除 | 固定費設定を変更・削除できる |

---

### 3-5. 締め日・表示設定

| # | 機能 | 詳細 |
|---|---|---|
| E-1 | 締め日の設定 | ユーザーごとに開始日（1〜31）と締め日（1〜31）を設定できる |
| E-2 | カレンダー・集計への反映 | 設定した締め日ベースで月次集計・カレンダー表示の期間が変わる |
| E-3 | デフォルト | 未設定の場合は1日〜末日（カレンダー月）を使用 |
| E-4 | 週の始まり曜日設定 | ユーザーごとに日曜始まり or 月曜始まりを選択できる |
| E-5 | カレンダーへの反映 | 設定した週の始まり曜日がカレンダーの列順に反映される |

例: 開始21日・締め20日 → 21日〜翌月20日を「1ヶ月」として扱う

---

### 3-6. カレンダー表示

| # | 機能 | 詳細 |
|---|---|---|
| F-1 | 月次カレンダー | 締め日設定に基づいた月次カレンダーを表示 |
| F-2 | 収支の表示 | 各日付マスに当日の収支内容・金額を表示 |
| F-3 | 緑テープ表示 | 最初の収入登録日から締め日まで緑のテープバーを表示 |
| F-4 | 赤テープへの切り替え | 収支累計が赤字に転落した日から締め日まで赤テープに切り替わる |
| F-5 | 固定費の表示 | 引き落とし日（土日祝ずらし後）に固定費を表示 |

---

### 3-7. 月次集計

| # | 機能 | 詳細 |
|---|---|---|
| G-1 | 収支サマリー | 締め日ベースの期間内で収入合計・支出合計・残高を表示 |
| G-2 | カテゴリ別集計 | カテゴリごとの支出合計を表示 |

---

## 4. 非機能要件

| 項目 | 内容 |
|---|---|
| レスポンシブ | スマートフォンでも快適に操作できる |
| セキュリティ | パスワードはbcryptでハッシュ化、JWT or セッションで認証管理 |
| 祝日データ | 日本の祝日に対応（holiday_jp gem等を使用） |

---

## 5. 対象外（スコープ外）

- グラフ・可視化機能（将来拡張）
- 予算上限設定・アラート機能（将来拡張）
- クレジットカード明細のインポート
- プッシュ通知

---

## 6. 用語定義

| 用語 | 定義 |
|---|---|
| グループ | 家計簿を共有する単位（家族・同居人など） |
| 締め日 | ユーザーが設定する月次集計期間の終了日 |
| 開始日 | ユーザーが設定する月次集計期間の開始日 |
| 固定費 | 毎月決まった金額・日付で発生する支出 |
| テープ表示 | カレンダー上で収支状況をビジュアルに示す横バー |
| 翌営業日 | 土日祝を除いた次の平日 |
